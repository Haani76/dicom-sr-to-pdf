    About

    What is a DICOM Structured Report?

    DICOM is the standard file format for medical imaging. Besides images, machines save a Structured Report (SR): a file holding every measurement taken during the exam (diameters, velocities, times, volumes) as a tree of coded entries. Software reads it easily, but people need a DICOM viewer, and even then it shows as a raw list full of codes.

    What does this tool do?

    It reads the SR and lays it out as a report: a patient and study header, sections, and measurement tables with values, units and qualifiers such as laterality. It hides technical codes, trims trailing zeros (it never rounds), and shows identical repeated readings once. Every page has page numbers. Tick Technical details to see everything exactly as stored.

    Is my data safe?

    Yes. The converter runs inside your browser. Your files are not uploaded to any server, and the PDFs are created on your own device. The page only downloads the converter program itself (Python running in the browser, via the Pyodide project), and the browser caches it.

    Does it show everything in the file?

    After each conversion it checks that every name and value in the SR appears in the PDF. If anything can't be shown, that file is marked with a warning naming what's missing.

    Important

    The PDF is a readable rendering of the SR, not a signed clinical report, and it doesn't interpret the measurements.
